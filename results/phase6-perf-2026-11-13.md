# Steady state: after the app's startup `PRAGMA optimize`

The run above has no index statistics: the worst case, straight after a bulk load, until the next restart or retention run. Without statistics SQLite reads the Google Reader unread ids through the full `(UserId, PublishedAt, ArticleId)` index (390 ms); with them it uses the unread partial index `IX_UserArticles_UnreadByDate` (about 40 ms). The run below is that steady state on the same data shape.
