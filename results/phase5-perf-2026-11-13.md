# Phase 5 performance run (2026-11-13)

SQLite file in WAL mode, real migrations (FTS5 triggers on). 500 sources in 20 folders, 200,000 articles for one user, 70% read, 1% saved, published over 120 days. Seeded in 55.4 s.
Machine: 4 logical CPUs, Microsoft Windows 10.0.19045, .NET 10.0.12. Each operation: 3 warm-up runs, then 20 timed runs.
